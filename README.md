# Sistema de Gestión de Pedidos — Principios SOLID

Proyecto de práctica en Java que implementa un sistema simple de gestión de pedidos,
evolucionado paso a paso para aplicar cada uno de los principios SOLID.

## Estado actual

Versión base sin aplicar principios SOLID todavía (punto de partida).

## Principios a aplicar

- [ ] S — Single Responsibility Principle
- [ ] O — Open/Closed Principle
- [ ] L — Liskov Substitution Principle
- [ ] I — Interface Segregation Principle
- [ ] D — Dependency Inversion Principle

## Cómo ejecutar

```
mvn compile exec:java -Dexec.mainClass="pe.jllalle.pedidos.Main"
```

O directamente desde IntelliJ IDEA, ejecutando la clase `Main`.
